# 🤖 Telegram Scheduler Bot

Bot de Telegram para programar publicaciones automáticas en canales y grupos.

## ✨ Características

- 📢 Añadir canales/grupos con validación de permisos
- 📝 Programar publicaciones: una vez, diaria, semanal o mensual
- 🎯 Publicar el mismo contenido en múltiples destinos a la vez
- 🎛 Gestión con botones inline (editar, pausar, borrar)
- 📊 Historial de envíos y logs
- 💼 Sistema de planes (free, basic, premium)
- 🗄 SQLite como base de datos
